# Factory Template

Vorlage für neue Projekte, die über die [Software Factory](https://github.com/AlexPEClub/software-factory) laufen. Stack-unabhängig: Den Stack legst du beim Start mit `/init` fest.

## Neues Projekt
- Auf GitHub: **Use this template**, oder mit dem Factory-Repo: `./scripts/new-project.sh mein-projekt`
- Briefing in `docs/briefing.md` legen
- Claude Code im Projekt starten: `/init`

Mehr in [CLAUDE.md](CLAUDE.md).
