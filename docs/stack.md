# Stack

> Wird mit `/init` festgelegt. Die Software Factory liest diese Datei vor jeder Architektur-, Build- und QA-Phase und hält sich daran.

- **Sprache / Laufzeit:** _z. B. TypeScript / Node 24_
- **Framework:** _z. B. Next.js (App Router)_
- **Oberfläche:** _z. B. Tailwind CSS + shadcn/ui_
- **Datenhaltung:** _z. B. Supabase (Postgres) oder localStorage_
- **Login:** _z. B. Supabase Auth oder keins_
- **Tests:** _z. B. Vitest + Playwright_
- **Paketmanager:** _z. B. npm_
- **Hosting:** _z. B. Hostinger VPS_
- **Stack-Packs:** _Factory-Hinweise für diesen Stack, z. B. `nextjs`, `supabase` (siehe Factory-Repo `workflows/starter-kit/stacks/`)_

## Konventionen
_Ordnerstruktur, Namensregeln, Besonderheiten. Was die Factory wissen muss, um sich in den Code einzufügen._

## Befehle
_Stehen in `.factory/setup.json` (install, dev, preview, checks)._
